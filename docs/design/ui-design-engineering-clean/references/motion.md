# Motion — 축소·재작성 기준

2026-10-02 편집: v2의 혼합 `motion.md` 전체를 복사하지 않았다. 별도 MIT 본문 고지가 없던 원천의 파생 관계를 넓게 제외하기 위해, 현재 사용자 규범 및 보존한 시각·접근성 원칙에서 필요한 일반 지침만 새로 서술한다. 원작 갤러리 코드·duration 표·curve 값·동작 데모는 포함하지 않는다. 관련 보존 원천 고지는 [고지](../THIRD_PARTY_NOTICES.md)에 있다.

## 무엇을 전달하는 효과인가

상태가 바뀌었다는 사실, 조작 대상과 결과의 관계, 현재 진행 상황 중 어느 것을 알려주는지 설명할 수 있는 효과를 사용한다. 원래 요구한 시각 방향을 임의로 삭제하지 않되, 효과가 입력 처리와 포커스 이동을 가로막지 않게 한다.

오류·성공·대기 상태는 정적인 문구와 형태로도 이해할 수 있어야 한다. 서버 응답이 불확실한데 성공 애니메이션을 보여주거나, animation 종료를 데이터 처리 완료로 삼지 않는다.

## 빠른 연속 조작과 중단

열기 도중 닫기, 연속 클릭, 키보드 이동, 뒤로 가기, 취소와 화면 이탈에서 실제 최종 상태·포커스·클릭 가능 요소가 맞는지 시험한다. 퇴장 중 투명한 요소가 조작을 가로채거나 이미 닫힌 overlay로 포커스가 돌아가면 구현 결함 후보이다.

## 사용자 설정과 성능

reduced motion에서 불필요한 이동을 줄이거나 없애도 필요한 상태와 행동을 잃지 않는다. 현재 제품의 사용자 선호를 확인하며 임의로 모든 효과를 상시 삭제하지 않는다. animation 시간·거리·scale을 이 자료로 고정하지 않는다.

성능은 해당 브라우저·장치 조건에서 관측한다. transform/opacity 등 속성 이름이나 GPU라는 문구만으로 부하와 반응속도를 보장하지 않는다. 지연이 보이면 이벤트 처리·렌더링·레이아웃·네트워크 등 실제 원인을 확인한다.
