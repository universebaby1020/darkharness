# 레이아웃·상태 — 일반 개념 선별 노트

이 문서는 원자료 R2/R3의 일반적인 설계 관점을 바탕으로 새로 작성한 참고 노트다. 원작 화면의 구도·문안·코드·측정 숫자·작품별 평가·랭킹을 재현하지 않는다. 과거 표본의 HIGH/MEDIUM 또는 빈도 기록을 이번 제품의 실증이나 사용자 확정 선호로 가져오지 않는다.

## 화면의 역할과 위계

주요 과업과 그다음 과업을 구분하고, 제목·본문·보조정보·조작의 상대적 중요도를 표현한다. 카드·배지·분할 패널을 실제 정보 구조가 필요로 할 때 사용한다. 기존 데스크톱 도구의 밀도나 패널 수를 소비자 웹앱에 그대로 강제하지 않는다.

## 색과 상태

선택, 실행 중, 경고, 실패, 성공을 서로 혼동하지 않도록 한다. 구분에는 문구·아이콘·형태 등도 쓰고 색만 의존하지 않는다. 특정 강조색/테마/폰트를 이 노트가 정하지 않는다. 원작 제품의 브랜드 자산·UI 스킨을 복사하지 않는다.

## 정보량과 반응형

좁은 화면에서 중요한 정보·조작이 사라지는지, 긴 문구·확대·데이터가 레이아웃을 깨뜨리는지 확인한다. 수평 스크롤·고밀도 표·접이식 패널은 쓰임새에 따라 타당할 수 있다. 의도된 스크롤 영역을 전체 문서 overflow와 구분하고, 단순 픽셀 차이로 사용자 영향 없는 finding을 양산하지 않는다.

## 시간에 따른 상태

초기/빈 상태, 진행 중, 결과, 오류, 불확실한 응답, 복구를 제품 계약이 구분하는 만큼 표현한다. 스피너 하나로 모든 상황을 뭉개지 않고, 존재하지 않는 승인·권한·자동 재시도 정책을 새로 만들지도 않는다. 이전 갤러리에서 본 approval 카드나 hold-to-act는 현재 제품에 그 동작을 추가할 허락이 아니다.

## 검증

정지 이미지는 동작·접근성·반응속도의 시험 결과가 아니다. 설계 참고는 실제 브라우저 관측으로 이어지고, 비교 기준과 관측 증거가 같은 계보의 자기주장만 되지 않도록 한다. 독립 검토가 없는 첫 screenshot은 baseline 후보일 뿐이다.
