# 출처와 선별 범위

입력: 사용자 제공 UI v2, 데스크톱 시각 prior R2, 동적 보조자료 R3. 이 편집은 원본을 변경하는 것이 아니라 새 배포 후보를 구성하는 작업이다.

## 포함

- 사용자 공통철학 및 업무 비특화 공통 지침 발췌.
- 라이선스 고지와 연결한 visual craft, accessibility, browser verification, shadcn 참조.
- 혼합 모션 파일 전체를 제외하고 새로 서술한 축소 모션 지침.
- 원작 구도·문안·코드·수치·랭킹을 포함하지 않는 일반 레이아웃·상태 개념 노트.

## 제외

원작 이미지·컨택트시트·갤러리 조사 레코드·출처별 동작 수치·HTML 데모·제한 조건이 있는 진단 스킬과 그 자동 호출/파생 참조를 포함하지 않는다. 제외 자료를 자동 재다운로드하거나 “원본 필요” 링크를 따라 입력에 넣는 단계도 없다. 디자인 영역에 필요한 기능을 삭제한 제품이 아니라 참고자료 선택본이다.

## 배포와 실행

이 팩에 원작 이미지가 없다는 사실이 향후 생성하는 모든 앱의 법적 무위험을 보증하지는 않는다. 실제 앱에 별도로 추가되는 아이콘·폰트·사진·라이브러리의 조건은 해당 자산을 도입할 때 확인한다. 사용자 원본 파일은 그대로 보존한다.

도구 버전은 설치 시 실제 환경에서 결속한다. 이 스킬은 CLI/MCP 설치·seat별 로딩·runtime 작동을 보장하지 않는다. package 검사와 제품 시험을 구분한다.
